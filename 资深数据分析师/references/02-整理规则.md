# 阶段二 · 数据整理规则（修复 + 必问项 + 变更日志）

整理只改副本，产出 `原文件名_已整理.xlsx` + `变更日志.md`。原表、体检标注副本一律不动。

## 一、三类必须先问用户的业务判断

不擅自拍板，列 2–4 个具体选项让用户选：

1. **检查项 2 单位口径**：同一列最终统一成什么单位？换算系数多少？
2. **检查项 8 去重主键**：按哪个字段判断同一笔记录？重复行删、留首行还是合并？
3. **检查项 5 是否拆分**：拆不拆？拆成哪几列？原列留不留？

其余判断（列名确切含义、多表字段命名）同样"能问就问、问不了就标黄待确认"。

## 二、逐项修复规则

| 检查项 | 处理规则 |
| --- | --- |
| 1 合并单元格 | 拆开合并，按同组值向下填充，一行一条记录 |
| 2 单位混着写 | 统一成纯数字，单位移入表头"字段（单位）"，换算系数写进日志 |
| 3 日期格式乱 | 统一 `YYYY-MM-DD`；缺年份的 `MM/DD` 不编年，原样保留 + 整格标黄 |
| 4 数字夹字 | 剥离文字变纯数字；估算词（约/左右/暂定/未定）转数字后标黄 + 批注 |
| 5 一格装多信息 | 默认不动；用户要求时按分隔符拆成独立列 |
| 6 空格子 | 优先从别处推导真值；推不出填 `【待补充】` + 标黄 |
| 7 多余空行空列 | 删除空行空列，保证数据连续 |
| 8 重复记录 | 完全重复行删并保留首次；按主键去重先确认主键与合并规则 |
| 9 表头问题 | 删大标题行，保留真表头；含糊列名问清再改；去重名列 |
| 10 多表命名不统一 | 先给字段映射建议，用户确认后统一再合并 |

执行细则：

- **检查项 1**：先 `unmerge_cells` 再写值，否则写入被吞；多表列名标题按检查项 9 处理。
- **检查项 3**：兼容 `2024/1/5`、`2024.1.5`、`2024年1月5日`、`20240105`、Excel 序列号；datetime 对象直接格式化；`01/21` 不猜年份，标黄。
- **检查项 4**：剥离 `约`、`左右`、`元`、`，`、全角空格；`未定`/`暂定` 写 `【待确认】`。
- **检查项 6**：不得用 0、`-`、空字符串冒充缺失值。
- 工作表含图表/透视表/图片时先提示用户 openpyxl 另存可能丢失这些对象。

## 三、人工复核可视化

所有待人工复核单元格：填充黄色 `FFFF00` + 批注，格式 `【资深数据分析师·数据整理】原值：xxx；原因：xxx；待您确认：xxx`。

必须标黄：缺年份日期、估算值、空格子、待确认删留的重复行、报告标"建议人工复核"且本次未改的项。

## 四、技术写法

批量操作走 `scripts/sheet_fix.py`（五个子命令：clone / inspect / unmerge-fill / mark / audit）：

```bash
python3 scripts/sheet_fix.py clone 原表.xlsx 原表_已整理.xlsx
python3 scripts/sheet_fix.py unmerge-fill 原表_已整理.xlsx --range A2:A10 --sheet 明细
python3 scripts/sheet_fix.py mark 原表_已整理.xlsx --cells D7 --note "原值：约1200；待您确认金额" --sheet 明细
python3 scripts/sheet_fix.py audit 原表_已整理.xlsx    # 核对标黄数与批注
```

- 脚本不覆盖的批量改写（日期归一、去重、删空行、改列名）用 openpyxl 写在副本上，写法见 `references/02a-openpyxl-recipes.md`。
- 日志模板见 `references/02b-变更日志模板.md`。

## 五、变更日志结构

1. **基本信息**：原文件名、已整理文件名、处理日期、本次处理的检查项、未处理的检查项。
2. **逐项变更记录**：按检查项分组，每条写清工作表、区域、原值→新值、处理方式、影响条数。
3. **统计汇总**：每项改了几处、总改动数。
4. **待人工确认**：位置、原值、原因、需要用户做什么。
5. **未处理项**：本次未动的检查项及原因。

## 六、自检

原表/标注副本未变 → 副本可正常打开、无多余空行空列 → 每个标黄格都有批注 → 日志改动数与表内实际一致 → 未改项都进了"待人工确认"。
