# 麦肯锡级商业分析：六条硬方法

这六条不是文风装饰，是每一步产出的合格线。写完报告/看板后逐条对照。

## 1. 结论先行（金字塔原理）

读者只记得住第一句。任何输出都按 `结论 → 3 个支撑理由 → 证据` 倒序组织，不按"我先做了什么"顺叙。

- 报告标题、每一段小标题、看板标题，一律写**判断句**：`毛利率下滑 2.1pct，主因是低毛利渠道占比上升`，而不是"毛利率情况"。
- 开头一段不超过 3 行就要把最重要的数字和判断说完。
- 每条结论必须能回答"所以呢（So What）"，答不出来的删掉。

## 2. MECE 拆解（相互独立、完全穷尽）

一个指标异常，先把它拆成互不重叠的加法/乘法结构，再定位到具体分支，不罗列一堆并列现象。

常用拆法：

| 场景 | 拆解式 |
| --- | --- |
| 营收变化 | 营收 = 客户数 × 客单价 × 复购次数；或 = Σ(各渠道量 × 各渠道价) |
| 利润变化 | 利润 = 营收 − 变动成本 − 固定费用；毛利率 × 周转率（杜邦） |
| 转化问题 | 漏斗逐层：曝光 → 点击 → 加购 → 下单 → 复购，定位流失最大的一层 |
| 人效问题 | 产出 = 人均产出 × 人头；人均产出 = 单量 × 单价 / 工时 |
| 时间对比 | 同比（周期性）+ 环比（近期动能）+ 结构（谁在变） |

每一层都要能算，算不出的层级就是"需补充数据"。

## 3. 假设驱动 + 问题树

先给 2–3 个最可能的解释（假设），再用数据逐条证伪，而不是把表里所有字段都描述一遍。

- 假设要写成可验证句：`假设 A：下滑来自渠道结构变化，而非单价下降`。
- 每条假设给"支持证据 / 反证 / 把握程度（高·中·低）"。
- 三个假设都被证伪是正常结果，此时明确写"数据不足以定位，需补 X"。

## 4. 对比与基准（没有基准的数字不算结论）

- 任何单点数字都要配一个参照：同比、环比、目标值、同类均值、上期值。
- 占比类必须同时给绝对数与百分比（总数小时尤其）。
- 涨跌用"上涨/下降 + 幅度 + 到多少"三层表述，不止给一个百分号。

## 5. 一张图一个论点

- 图题就是结论句，不写"各月营收趋势"。
- 图上只留支撑该结论的一组对比，删掉无关系列、网格线、装饰。
- 图表下方固定三句：`结论 → 证据（数字）→ 边界（口径/样本/不适用条件）`。

## 6. 落到决策（可执行、可衡量、可回指）

每条建议三要素：**动作 + 预期效果 + 衡量指标**，并回指某个具体发现。禁止"加强管理""提升效率"这类无动作句。

- 用 80/20 排序：先给影响最大的 1–2 条，其余归"次要项"。
- 自问：这条建议明天谁来执行？执行后看哪个数？答不出就重写。
- 数据撑不住的建议，改写成"还需补充的数据 + 补到后能判断什么"。

## 七条禁语（出现即返工）

1. "数据表明……"后面没有数字。
2. "整体表现良好/有待提升"这类无口径评价。
3. "A 导致 B"式因果表述（无对照实验时只能写"同时出现/可能原因"）。
4. 把每个字段都写一句的"字段说明书"。
5. 结论与图表不一致，或图里有 3 个以上发现。
6. 用 3D 图、双 Y 轴、红绿对比做"视觉冲击"。
7. 建议没有衡量指标。

## 用在本流水线里的位置

| 阶段 | 用哪几条 |
| --- | --- |
| 体检 | 只报影响下游计算的硬伤，按风险排序（80/20） |
| 整理 | 口径统一是有基准的前提（第 4 条） |
| 统计 | 指标设计按 MECE 拆解，避免重复计数（第 2 条） |
| 报告 | 结论先行 + 三假设排查 + 建议回指（1/3/6 条） |
| 看板 | 标题写结论、一图一论点、KPI ≤5 张（1/5 条） |
