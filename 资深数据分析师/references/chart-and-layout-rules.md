# 图表选型 · 配色 · 布局 · 解读规则

## 一、选型（由数据特征决定，不给用户出菜单）

| 数据长什么样 | 用什么图 | 注意 |
| --- | --- | --- |
| 随时间变化（月/周/日） | 折线（≥12 个点）或柱形（≤12 个点） | 时间轴必须等距、不跳期 |
| 类别之间比高低 | 纵向柱形（≤8 类） | 按数值降序排列，别按拼音 |
| 类别多、名称长（区域/客户/产品） | 横向条形 | 名称左对齐，数值右对齐 |
| 占比构成 | 环形图 / 饼图（**≤5 类**） | 超过 5 类合并「其他」或改条形 |
| 环节流失 | 漏斗 | 层数 3–5，标出每层转化率 |
| 单一目标达成 | 数字卡 + 进度条 / 仪表盘 | 只用于 1 个指标，不滥用仪表盘 |
| 两指标相关性 | 散点 | 先确认用户真的要分析相关性 |

**禁用**：3D 图、双 Y 轴、雷达图堆多项、会误导的堆叠面积（除非用户明确要结构变化）。

## 二、配色（≤4 色含灰）

- 一套图最多用 3 个彩色 + 1 个灰。灰专门给「其他 / 背景 / 参考线」。
- **禁红绿对比**（红绿色盲约 8% 男性）；正负/好坏用蓝橙或加箭头、加减号标记。
- 强调色只给「本次最想让人看见的那一个数」，不要满屏高亮。
- 文字对比度 ≥ 4.5:1；KPI 数字与背景对比度 ≥ 7:1（投屏优先）。
- 深色背景盘（大屏）可以用亮色数据线；普通会议室投屏优先浅底深字，抗环境光。

## 三、布局

- 顶部：标题（结论式）+ 一行元信息（数据口径 / 时间范围 / 来源）。
- KPI 区：3–5 张卡一行，按重要性从左到右，最重要的放最左；卡内「数值大、标签小、变化中」。
- 图表区：2 列栅格。趋势类占满整行（2 列），对比与占比并排，排名类单独一行。
- 一屏不超过 6 个图表区块；超了拆「主盘 + 附表页」或折叠。
- 留白：卡片间距 16–24px，卡片内边距 20–28px；宁松不挤。

## 四、投屏可读性（硬指标）

| 元素 | 最小字号 |
| --- | --- |
| 页面主标题 | 28px |
| 区块标题（结论句） | 20px |
| 正文 / 解读 | 15–16px |
| 坐标轴刻度 / 图例 | 12–13px |
| KPI 数值 | 40px 起，主 KPI 可 56–72px |

- 逻辑画布宽 ≥ 1200px，按 1920×1080 投屏检查；不要出现需要横向滚动的内容。
- 颜色之外必须有文字/符号冗余（不只靠颜色传达好坏）。

## 五、解读文案：结论 → 证据 → 边界

每张图下方固定三句，控制在每句 40 字内：

1. **结论**：这张图说明什么（可带方向与幅度）。「Q3 起营收加速，全年同比 +23%。」
2. **证据**：图里哪几个点/哪组对比支撑它。「7–9 月连续三月环比正增长，9 月为全年峰值。」
3. **边界**：这套数据不能推出什么、口径限制。「含 10 月预估值，且未剔除退货，绝对值仅供趋势参考。」

标题同理，写结论不写描述：`营收同比增长 23%` ✅ ／ `各月营收` ❌。

## 六、KPI 卡写法

- 标签：名词 + 口径（「营业收入（万元，同比）」）。
- 数值：只留 1 位小数以内，带千分位。
- 变化：方向符 + 幅度（▲ 23.4%），颜色只做辅助。
- 备注：一行说清对比基准（「对比 2024 年同期」），避免读者误读。
